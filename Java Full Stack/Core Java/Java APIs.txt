========================================================================================================================
Reflection 
========================================================================================================================

- Reflection is the capability to inspect and interact with classes, methods, constructors, fields, and interfaces at runtime, without necessarily knowing their details at compile time.


Class		Purpose

Class		Represents class metadata
Method		Represents a method
Field		Represents a field
Constructor	Represents a constructor
Modifier	Examines access modifiers such as private, public, static


Example:

class Employee {

    private int id = 101;
    private String name = "John";

    public void display() {
        System.out.println("Employee: " + name);
    }

    public void greet() {
        System.out.println("Hello!");
    }
}


Step 1: Get class information:

Class<?> clazz = Employee.class;



Step 2: Inspect methods:

Method[] methods = clazz.getDeclaredMethods();

for (Method method : methods) {
    System.out.println(method.getName());
}



Step 3: Invoke a method dynamically:

Employee emp = new Employee();
Method method = clazz.getDeclaredMethod("greet");
method.invoke(emp);



Step 4: Inspect and access private fields:

Field field = clazz.getDeclaredField("name");
field.setAccessible(true);
System.out.println(field.get(emp));




Reflection in Spring Boot:

- Spring performs framework-level operations using reflections like discovering classes annotated with @Controller, methods annotated with @GetMapping etc
