HTTPS (HyperText Transfer Protocol Secure)
=============================================================================================================================================================================

- HTTPS (HyperText Transfer Protocol Secure) is HTTP running over a secure and encrypted communication channel using TLS (Transport Layer Security).
- HTTPS provides secure communication between the Client and the Server by encrypting the data before it is transmitted over the network.
- HTTPS protects sensitive information such as Usernames, Passwords, Banking Information and Personal Data from being read or modified while travelling across the network.
- HTTPS provides three major security benefits:
  • Confidentiality – Prevents unauthorized users from reading the transmitted data.
  • Integrity – Ensures that transmitted data is not modified during communication.
  • Authentication – Verifies that the Client is communicating with the intended Server using Digital Certificates.
- HTTPS does not replace HTTP. It simply adds a security layer (TLS) before the data is transmitted over TCP.
- HTTPS also does not replace TCP. The communication stack becomes HTTP → TLS → TCP → IP.

Example:

Browser
   │
HTTPS Request
   │
TLS Encryption
   │
TCP
   │
Internet
   │
TCP
   │
TLS Decryption
   │
HTTP Request
   │
Spring Boot Application
