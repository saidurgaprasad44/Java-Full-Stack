------------------------------------------------------------
Run Maven Build
------------------------------------------------------------

- Right-click your project.
- Select Run As → Maven build... (choose the configuration dialog, not just Maven build).
- In the Goals field, enter: clean package
- Click Run

Goal	What it does
------------------------------------------------------------
clean	Removes the previous build output, normally the target/ directory.
compile	Compiles application source code.
test	Runs tests, if configured and not skipped.
package	Packages compiled code and resources into the configured artifact, typically a JAR.

------------------------------------------------------------
JAR
------------------------------------------------------------

- After a successful build, open your project directory in File Explorer.
- Find the jar in \target
- Open Windows Command Prompt and navigate to the project directory: 

cd C:\path\to\my-application

- Run the JAR: 

java -jar target\my-application-0.0.1-SNAPSHOT.jar

- If the application starts successfully, you'll see logs similar to:

Tomcat started on port 8080
Started MyApplication in 4.5 seconds

------------------------------------------------------------
Install and verify Docker Desktop / Docker Engine
------------------------------------------------------------



------------------------------------------------------------
Locate your JAR built by Maven
------------------------------------------------------------

Find the Jar file (inside /target) created by maven in previous stage

------------------------------------------------------------
Create the Dockerfile
------------------------------------------------------------

Create a file in project root folder naming "Dockerfile" with no extension and add the below content:


```
FROM eclipse-temurin:17-jre

WORKDIR /app

COPY target/quiz-0.0.1-SNAPSHOT.jar app.jar

EXPOSE 8080

ENTRYPOINT ["java", "-jar", "app.jar"]
```

------------------------------------------------------------
Build the image 
------------------------------------------------------------

- Open Command Prompt in the project root folder, where both Dockerfile and pom.xml are located and run:

docker build -t quiz-app:1.0 .

- The final . means Docker uses the current directory as its build context, so it can access the Dockerfile and the JAR under target/.
- After a successful build, list your images using below command in the terminal to verify the created image

docker images

- Or check the images in the images tab in Docker Desktop

------------------------------------------------------------
Start the Container
------------------------------------------------------------

docker run --name quiz-app-container -p 8079:8079 -e "SPRING_DATASOURCE_URL=jdbc:postgresql://host.docker.internal:5432/questiondb" quiz-app:1.0

--name quiz-app-container	Gives the container a convenient name
-p 8079:8079			Publishes a host port and maps it to that container port.
-e SPRING_DATASOURCE_URL=...	Overrides the Spring datasource URL for this container
host.docker.internal		Routes the database connection to your Windows host
quiz-app:1.0			Uses the image you built earlier

Try the applications endpoints and test

Stage 2 plan
1. Back up your existing Windows PostgreSQL database — protect your current schema and data.
2. Run PostgreSQL in Docker — create a database container with persistent storage.
3. Restore the existing database — copy its schema and data into the container.
4. Connect the Quiz app container to PostgreSQL — use Docker networking rather than host.docker.internal.
5. Verify the application — test the APIs and confirm the data is accessible.
6. Fresh database workflow — learn the steps and configuration only.




docker run -d `
  --name quiz-postgres `
  -e POSTGRES_DB=questiondb `
  -e POSTGRES_USER=quizuser `
  -e POSTGRES_PASSWORD=quiz123 `
  -p 127.0.0.1:5433:5432 `
  -v quiz-postgres-data:/var/lib/postgresql `
  postgres:18

docker run -d `
  --name quiz-app-container `
  --network quiz-network `
  -p 8079:8079 `
  -e "SPRING_DATASOURCE_URL=jdbc:postgresql://quiz-postgres:5432/questiondb_restore" `
  -e "SPRING_DATASOURCE_USERNAME=quizuser" `
  -e "SPRING_DATASOURCE_PASSWORD=quiz123" `
  quiz-app:1.0
