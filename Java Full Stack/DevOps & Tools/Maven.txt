

Goal	What it does
------------------------------------------------------------
clean	Removes the previous build output, normally the target/ directory.
compile	Compiles application source code.
test	Runs tests, if configured and not skipped.
package	Packages compiled code and resources into the configured artifact, typically a JAR.
install compiles and packages contracts, runs its tests, and installs the resulting JAR into your local Maven repository, usually under C:\Users\<your-user>\.m2\repository.


mvn -version
mvn clean package
mvn clean install
mvn compile
mvn package -DskipTests
mvn clean install -DskipTests
