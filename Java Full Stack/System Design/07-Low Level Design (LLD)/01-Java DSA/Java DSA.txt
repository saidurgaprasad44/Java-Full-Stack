2. Production-oriented Java coding
------------------------------------------------------------

Basic data manipulation:

- String processing, normalization and validation
- Array and collection transformations
- Removing duplicates while preserving order
- Frequency counting
- Searching and sorting
- Converting between arrays, lists, sets and maps
- Handling empty inputs, nulls and duplicates

Collections of objects:

Use models such as Employee, Product, Order, Customer and Transaction.
- Filter objects by multiple conditions
- Find maximum, minimum and matching objects
- Sort by one or multiple fields
- Group objects by a field
- Count objects by category
- Convert List<Employee> to Map<Long, Employee>
- Build lookup maps by ID
- Detect duplicate business keys
- Merge or reconcile collections
- Compare two collections to find additions, removals or changes

Maps and grouped data:

Map<Long, Employee>
Map<String, List<Employee>>
Map<String, Long>
Map<String, BigDecimal>

- Grouping employees by department
- Counting orders by status
- Summing transaction amounts by type
- Finding the most frequent item
- Indexing records by ID
- Grouping data with multiple levels of keys
- Combining values using merge() or computeIfAbsent()

Nested Structures:

Customer
└── List<Order>
       └── List<OrderItem>
             ├── Product
             ├── quantity
             └── unitPrice

- Extract all products across all orders
- Find customers who have placed qualifying orders
- Calculate order totals
- Calculate each customer's total spending
- Group order items by product
- Find the best-selling products
- Identify customers with no orders
- Handle missing or empty nested collections
- Flatten nested data using loops and flatMap()

ArrayList.get()       → generally O(1)
HashMap.get()         → O(1) average
HashSet.contains()    → O(1) average
TreeMap.get()         → O(log n)
List.contains()       → O(n)

Target: 5–8 programs

Frequency counting, deduplication, lookup, merging, grouping and sorting.
Target: 5–8 programs

Objects and nested structures:
Employee, order, product and transaction exercises; grouping, aggregation and nested extraction.
Target: 6–8 programs

Lambdas and streams:
Filtering, transformation, sorting, grouping, flattening and aggregation.
Target: 6–8 programs

------------------------------------------------------------
5. Complexity fundamentals
------------------------------------------------------------

Learn enough Big-O notation to compare common operations:

O(1): constant-time operation
O(log n): logarithmic growth
O(n): linear traversal
O(n log n): common efficient sorting
O(n square): nested full-array comparisons

Typical costs for:
array access
list insertion
searching
hash lookups
sorting and
heap operations.

- These are typical or average costs in some cases, not guarantees for every operation.
- Which data structure suits a problem and why, before writing Java code.

6. Important DSA patterns, algorithms and coding
------------------------------------------------------------

Array and string: traversal Searching, counting, reversing, in-place changes Essential
Hashing: Frequency maps, duplicate detection, pair lookup Essential
Sorting: Built-in sorting, sorting-based solutions Essential
Two pointers: Sorted pairs, palindrome, in-place removal High
Sliding window: Fixed/variable windows High
Prefix sums: Range sums and cumulative totals High
Binary search: Standard search, first/last occurrence High
Stack and queue: Parentheses, processing order Medium
Linked list: Reverse, middle, cycle detection Medium
Recursion: Base cases and recursive calls Basic
Trees: Traversals, depth, level-order traversal Basic
Heap / priority queue: Top-K, kth-largest Medium
BFS / DFS: Basic tree/graph/grid traversal Basic
Greedy: Simple interval or scheduling problems Introductory
Dynamic programming: Fibonacci, climbing stairs, memoization Introductory
