05 - Redis Fundamentals

* Why Redis is commonly used for distributed caching
* Redis data model and only the data structures relevant to architecture

String       -> useful for storing a serialized object, JSON document, token, or simple value.
Hash         -> useful for field-by-field access and updates.
List         -> useful for ordered collections, such as recent activity.
Set          -> useful for unique members, such as unique visitor IDs
Sorted Set   -> useful for ranking, such as top-selling products
