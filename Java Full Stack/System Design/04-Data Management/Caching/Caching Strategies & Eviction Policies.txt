* Choosing the right strategy and understanding trade-offs

| Strategy      | Who handles cache miss? | Write behavior               |
| ------------- | ----------------------- | ---------------------------- |
| Cache-Aside   | Application             | Application controls         |
| Read-Through  | Cache layer             | Separate decision            |
| Write-Through | Cache participates      | Synchronous datastore write  |
| Write-Behind  | Cache                   | Asynchronous datastore write |
