DDL:

CREATE:

-- 1. DEPARTMENT TABLE
CREATE TABLE department (
    department_id   INT PRIMARY KEY,
    department_name VARCHAR(100) NOT NULL
);


-- 2. EMPLOYEE TABLE
CREATE TABLE employee (
    emp_id          INT PRIMARY KEY,
    name            VARCHAR(100) NOT NULL,
    department_id   INT,
    salary          NUMERIC(12, 2),
    manager_id      INT,

    CONSTRAINT fk_employee_department
        FOREIGN KEY (department_id)
        REFERENCES department(department_id),

    CONSTRAINT fk_employee_manager
        FOREIGN KEY (manager_id)
        REFERENCES employee(emp_id)
);


-- 3. PROJECT TABLE
CREATE TABLE project (
    project_id      INT PRIMARY KEY,
    project_name    VARCHAR(150) NOT NULL,
    emp_id          INT,

    CONSTRAINT fk_project_employee
        FOREIGN KEY (emp_id)
        REFERENCES employee(emp_id)
);

Order of Query Execution:
------------------------------------------------------------

SELECT department_name, AVG(salary) AS avg_sal
FROM employee e
JOIN department d
ON e.department_id = d.department_id
WHERE salary > 50000
GROUP BY department_name
HAVING COUNT(*) >= 2
ORDER BY avg_sal DESC
OFFSET 2
LIMIT 10;

From -> Join On -> Where -> Group By -> Having -> Select columns -> Order By -> OFFSET -> LIMIT

2. Joins and subqueries
===================================================================================================================================================================

------------------------------------------------------------
JOIN (INNER JOIN)
------------------------------------------------------------

- Returns only matching records from both tables.

------------------------------------------------------------
LEFT JOIN (LEFT OUTER JOIN)
------------------------------------------------------------

Returns:
- All records from the left table.
- Matching records from the right table.
- NULL for right-table columns when there is no match.

------------------------------------------------------------
RIGHT JOIN (RIGHT OUTER JOIN)
------------------------------------------------------------

Returns:
- All records from the right table
- Matching records from the left table.
- NULL for left-table columns when there is no match.

------------------------------------------------------------
FULL JOIN (FULL OUTER JOIN)
------------------------------------------------------------

Returns:
- Matching records.
- Unmatched records from the left table.
- Unmatched records from the right table.

------------------------------------------------------------
SELF JOIN
------------------------------------------------------------

- A table joins with itself.
- Use Left join

CROSS JOIN
------------------------------------------------------------

UNION & UNION ALL
------------------------------------------------------------

- Combines rows from two compatible SELECT results vertically
- UNION removes duplicate rows
- UNION ALL retains duplicates and generally avoids the duplicate-elimination overhead

------------------------------------------------------------
Subqueries:
------------------------------------------------------------

Where can subqueries be used in a query:

- In SELECT clause (Scalar Subquery)
- In FROM / JOIN clauses (Derived Table)
- In WHERE clause
- In HAVING clause



Single-row subquery: 

- A subquery that generates a result of single row, single column 
- In WHERE & HAVING clauses, it must be used with <, >, =, !=, IS, NOT IS

Example: Find employees earning more than the average salary.

Query:

select *
FROM employee e
WHERE e.salary > (
	SELECT AVG(salary)
	FROM employee
)



Multi-row subquery:

- A subquery that generates a result of multiple rows, single column
- In WHERE & HAVING clauses, it is used with IN / NOT IN operators

Example: Find employees working in departments located in a particular department set.

Query:

SELECT e.name
FROM employee e
WHERE e.department_id IN (
	SELECT department_id
	FROM department
	WHERE department_name IN ('IT', 'HR')
)



Multi-column subquery:

- Subqueries that generate a result with multiple columns is compared with:
	- '=' if it is guaranteed to produce only one row
	- IN / NOT IN if there are multiple rows

Example: find the highest-paid employee(s) in each department.

Query:

select e.*
from employee e
where (e.salary, department_id) in (
	select max(salary), department_id
	from employee
	group by department_id
)

Correlated Subquery:

SELECT e.*
FROM employee e
WHERE e.salary = (
    SELECT MAX(e2.salary)
    FROM employee e2
    WHERE e2.department_id = e.department_id
);

Conditional Aggregation:
------------------------------------------------------------

Find the number of employees earning above and below 70,000 in each department.

SELECT
    department_id,
    COUNT(CASE WHEN salary > 70000 THEN 1 END) AS high_salary_count,
    COUNT(CASE WHEN salary <= 70000 THEN 1 END) AS low_salary_count
FROM employee
GROUP BY department_id;
